Política de Privacidade

Última atualização: 2 de novembro de 2026

Esta política descreve como o Chico Agent ("o aplicativo") trata informações obtidas de serviços do Google. O aplicativo é de uso estritamente pessoal e privado: possui um único usuário, que é seu próprio proprietário. Não é oferecido ao público, não permite cadastro e não atende terceiros.

1. Quem é o responsável

René Amato Gerin — contato: chicoagent.ai@gmail.com.

2. Quais dados do Google são acessados

O aplicativo acessa apenas as contas Google do próprio proprietário, e somente dentro dos escopos que ele autoriza expressamente:

  • Gmail (gmail.readonly, gmail.send, gmail.modify) — ler, enviar e organizar mensagens;
  • Google Calendar — ler e criar eventos na agenda;
  • Google Drive — localizar e organizar arquivos;
  • Google Contacts (contacts.readonly) — consultar contatos ao executar tarefas solicitadas;
  • Google Sheets e Docs — ler e escrever planilhas e documentos quando a tarefa exigir.

O aplicativo não acessa dados de outras pessoas, não coleta informações de visitantes deste site e não utiliza cookies, rastreadores ou ferramentas de análise.

3. Para que os dados são usados

Exclusivamente para executar as tarefas que o proprietário solicita, uma a uma — por exemplo: resumir compromissos do dia, criar um evento na agenda, encontrar um e-mail, emitir um lembrete de conta a pagar. Não há qualquer uso secundário.

Os dados não são usados para:

  • publicidade ou marketing de qualquer tipo;
  • treinamento de modelos de linguagem ou de aprendizado de máquina;
  • análise de perfil, pontuação ou decisões automatizadas sobre pessoas;
  • venda, aluguel ou licenciamento a terceiros.

4. Onde os dados ficam armazenados

O aplicativo roda no computador do próprio proprietário. Os dados obtidos do Google — mensagens, eventos e arquivos — são processados e permanecem localmente, na mesma máquina, e não são enviados a servidores próprios ou de terceiros mantidos pelo aplicativo.

O token de autorização OAuth é gravado em arquivo local com permissão restrita (leitura apenas pelo proprietário), usado unicamente para autenticar as chamadas à API do Google e renovado automaticamente enquanto a autorização estiver válida.

5. Compartilhamento com terceiros

Nenhum dado é compartilhado, vendido, alugado ou transferido a terceiros. Não há integrações de anúncios, corretores de dados ou serviços de análise. O aplicativo não transfere informações obtidas do Google para plataformas de anúncio, redes sociais ou qualquer outro destinatário.

6. Retenção e exclusão

Os dados ficam retidos apenas enquanto forem úteis à tarefa solicitada, no próprio computador do proprietário. O proprietário pode, a qualquer momento:

  • revogar o acesso do aplicativo em myaccount.google.com/permissions;
  • apagar o token local, o que encerra imediatamente a capacidade do aplicativo de acessar as contas Google;
  • excluir quaisquer dados locais armazenados pelo aplicativo.

Como o único titular dos dados é o próprio proprietário, a exclusão é feita por ele diretamente, sem necessidade de solicitação a terceiros.

7. Segurança

O acesso se dá exclusivamente por OAuth 2.0 do Google, com escopos mínimos necessários. As credenciais não são compartilhadas, não trafegam em texto aberto e ficam em arquivo local de permissão restrita. O aplicativo não mantém servidor público que armazene dados de usuários.

8. Política de Dados do Usuário dos Serviços de API do Google

O uso e a transferência, pelo Chico Agent, de informações recebidas das APIs do Google observam a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado (Limited Use).

Chico Agent's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

9. Crianças

O aplicativo não é destinado a menores de idade e não é disponibilizado a nenhum usuário além do proprietário.

10. Alterações nesta política

Eventuais mudanças serão publicadas nesta mesma página, com atualização da data no topo. Como o aplicativo tem um único usuário, o proprietário é diretamente informado de qualquer alteração.
